# amnezia-awg-users

Массовое создание пользователей AmneziaWG 3.1 с выдачей ключей `vpn://` для приложения [Amnezia VPN](https://amnezia.org).

На вход — список имён, на выход — список ключей:

```
Петя Иванов: vpn://AAAB...
Mary Ann [iPhone]: vpn://AAAB...
vasya: vpn://AAAB...
```

Скрипт работает с сервером, который установило само приложение Amnezia (контейнер `amnezia-awg2`). Пользователи, созданные скриптом, видны и в приложении. Добавление и удаление применяются сразу, без перезапуска VPN.

## Требования

- VPS с AmneziaWG 3.1, установленным через приложение Amnezia
- доступ к серверу по SSH под root
- Python 3.8+ на сервере (на Ubuntu и Debian обычно уже есть)

## Установка

На своём компьютере (PowerShell или терминал):

```
scp awg-users.py root@IP_СЕРВЕРА:/root/
ssh root@IP_СЕРВЕРА
```

На сервере:

```
cd /root
python3 --version
chmod +x awg-users.py
docker cp amnezia-awg2:/opt/amnezia/awg /root/awg-backup   # резервная копия
```

Или сразу на сервере, без копирования с компьютера:

```
curl -O https://raw.githubusercontent.com/WildKlorik/amnezia-awg-users/main/awg-users.py
chmod +x awg-users.py
```

## Образец ключа (один раз)

Скрипт берёт за образец настоящий ключ из приложения и подставляет в него ключи и IP каждого нового пользователя. Так формат гарантированно совпадает с приложением.

1. В приложении Amnezia: сервер → «Поделиться» → пользователь `template`, протокол AmneziaWG, формат «ключ vpn://». Скопируйте ключ.
2. На сервере выполните `./awg-users.py template` и вставьте ключ.
3. Пользователя `template` можно удалить в приложении — образец продолжит работать.

Образец нужно записать заново после переустановки протокола или переезда на новый сервер. Скрипт предупредит, если образец не совпадает с сервером.

## Использование

Создайте `names.txt` с одним именем на строку (пример — в [names.example.txt](names.example.txt)) и запустите:

```
./awg-users.py add -f names.txt
```

Ключи выводятся на экран вместе с именами, а в файл `/root/awg-clients/keys-ДАТА-ВРЕМЯ.txt` сохраняются только ключи, по одному на строку, в том же порядке, что и имена в списке.

| Команда | Что делает |
| --- | --- |
| `./awg-users.py add -f names.txt` | создать пользователей из файла |
| `./awg-users.py add vasya "Петя Иванов"` | создать пользователей, перечисленных в команде |
| `./awg-users.py show "Петя Иванов"` | показать ключ пользователя ещё раз |
| `./awg-users.py del vasya "Петя Иванов"` | удалить пользователей, в том числе созданных в приложении |
| `./awg-users.py list` | пользователи, их IP и время последнего подключения |

Имена могут содержать пробелы, кириллицу и скобки (до 64 символов, без `/` и `\`). В командной строке имена с пробелами берите в кавычки. Файл со списком можно сохранить в Блокноте в любой кодировке.

Скачать ключи на компьютер:

```
scp "root@IP_СЕРВЕРА:/root/awg-clients/keys-*.txt" .
```

## Настройки

В начале `awg-users.py`:

| Параметр | По умолчанию | Что это |
| --- | --- | --- |
| `CONTAINER` | `amnezia-awg2` | имя Docker-контейнера AmneziaWG |
| `AWG_DIR` | `/opt/amnezia/awg` | папка настроек внутри контейнера |
| `IFACE` | `awg0` | имя интерфейса |
| `CLIENTS_DIR` | `/root/awg-clients` | где хранятся ключи и образец |

## Если что-то пошло не так

| Что видите | Что делать |
| --- | --- |
| `/usr/bin/env: 'python3\r'` | `sed -i 's/\r$//' awg-users.py` (файл сохранён с переносами строк Windows) |
| `Permission denied` при запуске | `chmod +x awg-users.py` |
| «нет образца ключа» | `./awg-users.py template` |
| «параметры обфускации не совпадают с сервером» | протокол переустанавливали — запишите образец заново |
| «контейнер не запущен» | проверьте `docker ps` и параметр `CONTAINER` |

Восстановление из резервной копии:

```
docker cp /root/awg-backup/. amnezia-awg2:/opt/amnezia/awg/
docker restart amnezia-awg2
```

## Безопасность

Ключи `vpn://`, файлы в `/root/awg-clients` (включая `template.json`) и списки имён содержат приватные ключи и личные данные. Не добавляйте их в репозиторий — `.gitignore` уже исключает их на случай, если вы работаете в клоне.

## Как это устроено

- ключи пользователя генерируются через `awg genkey`/`awg genpsk` внутри контейнера;
- пользователь добавляется на лету командой `awg set` и дописывается в `awg0.conf`;
- запись добавляется в `clientsTable`, чтобы пользователь был виден в приложении Amnezia;
- ключ `vpn://` собирается из образца: это сжатый (Qt `qCompress`) JSON в base64url, в котором заменяются приватный и публичный ключи, preshared key и IP.

Проект не связан с командой Amnezia. Протокол 3.1 новый, поэтому после обновлений Amnezia проверяйте работу на одном пользователе.
